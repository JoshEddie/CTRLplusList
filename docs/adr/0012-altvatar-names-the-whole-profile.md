# "Altvatar" is the user-facing name for a whole profile

The term started as the name for a profile's generated artwork and was widened
to mean the profile itself — the alter ego that owns lists, can be co-owned or
managed, and has a "look". Code and schema keep saying `profile`; the two
vocabularies are deliberately different, and `CONTEXT.md` records both sides.

Reverting was considered: the app's usage shape is infrequent, so a user may
meet the word once at onboarding and return months later having forgotten it,
and the schema disconnect is real. It was kept because the concept — a
list-keeper without its own sign-in — is one "profile" does not communicate, and
the landing page, onboarding gate, and image postal already teach it.
